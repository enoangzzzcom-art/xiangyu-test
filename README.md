# 相遇 · 婚恋条件测评

免费的静态网站演示：38项问卷、9维条件参考分、理想型与底线型画像、可调整权重，以及文字报告下载。

原创规则未经市场样本校准，不提供真实婚恋排名或成功率。本项目不是原小红书测试的官方版本，与原作者无关联。

答题与计分均在浏览器完成，答卷不上传服务器。进度使用当前标签页的会话存储。没有支付、账号系统或第三方统计脚本。

## GitHub Pages 发布

1. 将这些文件上传至仓库的 `main` 分支根目录。
2. 在仓库 `Settings → Pages` 中选择 `Deploy from a branch`。
3. 选择 `main` 与 `/ (root)`，保存。
4. 等待 Pages 部署完成，使用设置页返回的网站地址。

`.nojekyll` 禁用不需要的 Jekyll 处理。页面使用相对资源路径和 hash 路由，可在项目子路径下运行。

本版本仅用于免费演示。收费业务需要适合商业用途的运行托管及服务端订单、支付、鉴权等功能。
